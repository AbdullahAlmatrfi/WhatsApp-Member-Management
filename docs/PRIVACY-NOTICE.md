# Privacy Notice / إشعار الخصوصية

> **For the gym owner (delete this box before printing).**
> Fill in the three placeholders: **[Gym name]**, **[N days]**, **[contact]**.
> [N days] must match the auto-delete window set in the admin console (72 hours = 3 days, 48 hours = 2 days, 24 hours = 1 day).
> Put this on the sign-up form with the consent box below, and at the desk. This is a template, not legal advice. Have a Saudi lawyer review the wording.

### Notes for the owner (not printed)

- **Honor "STOP" / "إيقاف":** delete the person or never message them again, the same day. Keep your own "do not message" note so they are not re-added by mistake. See `docs/SECURITY-AND-PRIVACY.md`, section 6.
- **Keep the signed forms** (or opt-in screenshots) as your record of consent. The app does not store consent.
- **The Arabic block should be right-to-left** when you lay out the printed page.
- **Add "Reply STOP / أرسل إيقاف لإلغاء الاشتراك"** to every broadcast message, and start each message with the gym name.
